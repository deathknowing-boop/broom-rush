# 风行

二次元贴地疾飞的网页小游戏：骑着扫帚贴着海面、草坡和花田高速掠过。点开就能玩 → https://deathknowing-boop.github.io/broom-rush/

**玩什么**：风之试炼（海风测速、海崖线、海崖大跳、和 7 位 AI 伙伴的海崖竞速）、九段「旅程」目标、派对「风之祭」（抢风铃 / 花瓣乱斗 / 抢花环 / 竞速四轮积分）、边飞边放花环自己修航线并用链接分享。

**电脑**：鼠标转向，W / Shift / 左键加速，S / 右键减速，空格拉起（大跳时在空中按 = 特技），Tab 旅程与派对，G 打招呼，E 修航线，R 再来一次，F 全屏，N 音乐，I 帧率。

**手机**：横屏，左手拖动转向，右下按住加速（空中点一下 = 特技），左上「旅程」。
